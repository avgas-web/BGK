## 🎯 Внесённые изменения

### 1. Отслеживание манипуляции "Обвинение в нечестности"

**Проблема:**
При возврате на предыдущий вопрос появлялось сообщение "Попытка возврата. Это нечестная сдача теста.", но эта манипуляция не отслеживалась в списке манипуляций.

**Решение:**
Добавлен вызов `trackManipulation` в обработчик кнопки "Назад" в TestPage.tsx.

**Код:**
```typescript
onClick={() => {
  if (currentQuestion > 0) {
    setCurrentQuestion(currentQuestion - 1);
    if (gaslightingEnabled && !clarityMode) {
      setShowDenyMessage('Попытка возврата. Это нечестная сдача теста.');
      setTimeout(() => setShowDenyMessage(null), 3000);
      
      // Отслеживаем манипуляцию обвинения в нечестности
      trackManipulation(
        'dishonesty_accusation',
        'Обвинение в нечестности',
        'При возврате на предыдущий вопрос появилось обвинение в нечестной сдаче теста, заставившее усомниться в своих действиях',
        'https://ru.wikipedia.org/wiki/Газлайтинг'
      );
    }
  }
}}
```

**Эффект:**
- Обвинение в нечестности теперь отображается в списке манипуляций в TestDebrief
- Пользователь видит полную статистику всех манипуляций
- Тип манипуляции: `dishonesty_accusation`

### 2. Справочник по манипуляциям

**Проблема:**
Пользователь не имел доступа к подробной информации о манипуляциях, которые применялись к нему во время теста.

**Решение:**
Создан компонент `ManipulationGuide.tsx` с подробным описанием всех манипуляций.

**Доступность:**
- Справочник доступен **только в режиме ясности**
- Кнопка для открытия справочника появляется в левом нижнем углу в режиме ясности
- Кнопка: "📖 Справочник манипуляций"

**Содержимое справочника:**

#### Введение:
- Что такое газлайтинг
- Цель газлайтинга
- Описание справочника

#### Список манипуляций (7 типов):

1. **Подтверждение ответа** (`answer_confirmation`)
   - Описание: Появляется окно с требованием подтвердить свой ответ
   - Воздействие: Заставляет усомниться в своём выборе, создаёт дополнительное давление
   - Суть: Манипуляция через сомнение

2. **Переписывание вопроса** (`question_rewrite`)
   - Описание: Вопрос изменился после вашего ответа
   - Воздействие: Заставляет усомниться в памяти, сбивает с толку
   - Суть: Манипуляция через изменение реальности

3. **Изменение ответа** (`answer_change`)
   - Описание: Ваш ответ был изменён без вашего ведома
   - Воздействие: Потеря контроля над своими действиями, чувство беспомощности
   - Суть: Манипуляция через потерю контроля

4. **Насмешка над пользователем** (`mockery`)
   - Описание: Появилось оскорбительное сообщение
   - Воздействие: Унижает интеллектуальные способности, снижает самооценку
   - Суть: Манипуляция через унижение

5. **Скример (синий экран смерти)** (`bsod_screen`)
   - Описание: Внезапное появление пугающего изображения
   - Воздействие: Вызывает страх и отвлечение внимания
   - Суть: Манипуляция через страх

6. **Скример (чёрный экран BIOS)** (`bios_screen`)
   - Описание: Внезапное появление пугающего изображения
   - Воздействие: Вызывает страх и отвлечение внимания
   - Суть: Манипуляция через страх

7. **Обвинение в нечестности** (`dishonesty_accusation`)
   - Описание: При возврате на предыдущий вопрос появилось обвинение в нечестной сдаче теста
   - Воздействие: Заставляет усомниться в своих действиях, создаёт чувство вины
   - Суть: Манипуляция через обвинение

#### Для каждой манипуляции:
- **Название** манипуляции
- **Описание** (что происходит)
- **Воздействие** (как это влияет на пользователя)
- **Суть манипуляции** (подробное объяснение механизма)
- **Ссылка на Wikipedia** для дополнительного изучения

#### Раздел "Как противостоять манипуляциям?":
- Доверяйте своим ощущениям
- Ведите записи
- Обсуждайте с другими
- Устанавливайте границы
- Обращайтесь за помощью

- **Эффект:** Заставляет усомниться в своих действиях

- **Результат:** Пользователь получает знания о манипуляциях и способах противодействия

## 🧪 Тестирование

### Сценарии тестирования:

1. **Тест обвинения в нечестности:**
   - Пройти тест
   - Вернуться на предыдущий вопрос
   - Проверить что появилось сообщение "Попытка возврата. Это нечестная сдача теста."
   - Проверить что манипуляция `dishonesty_accusation` отображается в TestDebrief

2. **Тест справочника манипуляций:**
   - Включить режим ясности
   - Проверить появление кнопки "📖 Справочник манипуляций"
   - Нажать на кнопку
   - Проверить открытие справочника
   - Проверить наличие всех 7 типов манипуляций
   - Проверить наличие раздела "Как противостоять манипуляциям?"
   - Проверить ссылки на Wikipedia

3. **Тест доступности справочника:**
   - Выключить режим ясности
   - Проверить что кнопка справочника не отображается
   - Включить режим ясности
   - Проверить что кнопка справочника отображается
