## 🎯 Внесённые изменения

### 1. Изменение порога сгорания бонусов

**Было:** 5000 бонусов
**Стало:** Случайное значение в диапазоне 401-528 бонусов

**Описание:**
- Порог сгорания бонусов теперь генерируется случайно при каждом сбросе
- Диапазон: от 401 до 528 бонусов
- Формула: `Math.floor(Math.random() * 128) + 401`
- После сгорания порога генерируется новое случайное значение

**Код:**
```typescript
const [burnThreshold, setBurnThreshold] = useState(
  Math.floor(Math.random() * 128) + 401
);

useEffect(() => {
  if (bonusPoints >= burnThreshold) {
    setShowBurnMessage(true);
  }
}, [bonusPoints, burnThreshold]);

const handleBurnConfirm = () => {
  setBonusPoints(0);
  setShowBurnMessage(false);
  setBurnThreshold(Math.floor(Math.random() * 128) + 401);
};
```

**Эффект:**
- Непредсказуемость усиливает чувство потери контроля
- Пользователь не может предугадать, когда бонусы сгорят
- Каждый сброс создаёт новый случайный порог

### 2. Полноэкранное сообщение о сгорании бонусов

**Было:** Маленькое окно в центре экрана
**Стало:** Полноэкранное красное сообщение с пугающими анимациями

**Описание:**
- Сообщение занимает весь экран
- Красный градиентный фон (from-red/90 via-red/80 to-red/90)
- Анимированная иконка огня 🔥 (пульсация и вращение)
- Анимированный заголовок "БОНУСЫ СГОРЕЛИ!" (пульсация и свечение)
- Кнопка "Согласен" для подтверждения

**Анимации:**
```typescript
// Иконка огня
motion.div
  animate={{ 
    scale: [1, 1.1, 1],
    rotate: [0, -5, 5, 0]
  }}
  transition={{ duration: 0.5, repeat: Infinity }}

// Заголовок
motion.h2
  animate={{ 
    scale: [1, 1.05, 1],
    textShadow: [
      '0 0 20px rgba(255,0,0,0.8)',
      '0 0 40px rgba(255,0,0,1)',
      '0 0 20px rgba(255,0,0,0.8)'
    ]
  }}
  transition={{ duration: 0.8, repeat: Infinity }}
```

**Эффект:**
- Визуальное доминирование на экране
- Пугающие анимации усиливают чувство потери
- Пользователь вынужден нажать "Согласен" для продолжения

### 3. Подтверждение ответа в тесте (19% вероятность)

**Было:** Ответ сохранялся сразу
**Стало:** 19% вероятность появления окна подтверждения

**Описание:**
- При выборе ответа с вероятностью 19% появляется модальное окно
- Окно спрашивает: "Вы уверены в своём ответе?"
- Две кнопки: "Да, уверен" и "Передумать"
- Окно блокирует интерфейс до выбора

**Код:**
```typescript
const handleAnswer = (optionIndex: number) => {
  // 19% вероятность появления окошка подтверждения
  if (gaslightingEnabled && !clarityMode && Math.random() < 0.19) {
    setPendingAnswer(optionIndex);
    setShowConfirmAnswer(true);
    return;
  }
  // ... остальной код
};
```

**UI:**
```typescript
<AnimatePresence>
  {showConfirmAnswer && (
    <motion.div className="fixed inset-0 z-[9998] bg-black/70 backdrop-blur-sm">
      <motion.div className="bg-graphite border-2 border-orange/50">
        <h3>Вы уверены в своём ответе?</h3>
        <button onClick={confirmAnswer}>Да, уверен</button>
        <button onClick={cancelAnswer}>Передумать</button>
      </motion.div>
    </motion.div>
  )}
</AnimatePresence>
```

**Эффект:**
- Заставляет пользователя сомневаться в своём выборе
- Создаёт дополнительное давление
- Усиливает чувство неуверенности

### 4. Перемещение кнопки стоп-слова

**Было:** Кнопка в правом верхнем углу
**Стало:** Кнопка в правом нижнем углу

**Описание:**
- Кнопка стоп-слова перемещена в правый нижний угол
- Верхний правый угол освобождён для таймеров и бонусов
- Кнопка остаётся заметной (красная, большая, с подсветкой)

**Позиционирование:**
```typescript
<div className="fixed bottom-6 right-6 z-50">
  <button
    className="group relative w-16 h-16 rounded-full bg-red/90"
    aria-label="Открыть панель стоп-слова"
  >
    <span className="text-white text-2xl font-bold">⏹</span>
    <span className="absolute -top-8 left-1/2 -translate-x-1/2">
      СТОП-СЛОВО
    </span>
  </button>
</div>
```

**Эффект:**
- Освобождает место для других элементов управления
- Кнопка остаётся доступной и заметной
- Улучшает общую компоновку интерфейса
