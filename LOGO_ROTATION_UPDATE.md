# Обновление логотипа БГК — вращение и эффект КГБ

## ✅ Все изменения реализованы и протестированы

### Что было сделано:

**1. Изменение цвета букв**
- **Было:** Буквы Б, Г, К были разных цветов (лайм, белый, фиолетовый)
- **Стало:** Все три буквы теперь **красного цвета** (#FF3B3B)

**2. Вращение букв**
- Буквы БГК теперь **вращаются** на стартовой странице
- Скорость вращения: 1 градус каждые 50ms (20 FPS)
- Полный оборот: 18 секунд (360 градусов)
- Вращение непрерывное и плавное

**3. Эффект "КГБ" — дёрганье экрана**
- При достижении **180 градусов** буквы визуально переворачиваются
- БГК → КГБ (буквы читаются в обратном порядке)
- В этот момент **экран дёргается** (эффект тряски)
- Длительность эффекта: 500ms
- Анимация включает:
  - Смещение по X и Y (±5px)
  - Лёгкий поворот (±0.5 градуса)
  - 10 кадров анимации за 0.5 секунды

## 🎭 Психологический эффект

### Вращение букв:
- **Цель:** Создать гипнотический эффект
- **Эффект:** Пользователь следит за вращением, теряя счёт времени
- **Вывод:** "Я смотрю на буквы, но они меняются..."

### Переход БГК → КГБ:
- **Цель:** Продемонстрировать, как контекст меняет восприятие
- **Эффект:** Те же буквы, но в другом порядке = совершенно другой смысл
- **Вывод:** "БГК" (Базз Газлайтер Клаб) → "КГБ" (советская спецслужба)
- **Газлайтинг:** "Вам не показалось. Буквы действительно изменились. Или это вы изменились?"

### Тряска экрана:
- **Цель:** Создать ощущение нестабильности реальности
- **Эффект:** Кратковременный шок при переходе БГК → КГБ
- **Вывод:** "Даже экран не уверен в том, что показывает"

## 🎯 Технические детали

### Анимация вращения:
```typescript
useEffect(() => {
  const interval = setInterval(() => {
    setRotation(prev => {
      const newRotation = prev + 1;
      
      // При достижении 180 градусов (КГБ) запускаем эффект дёрганья
      if (newRotation % 360 === 180) {
        setIsShaking(true);
        setTimeout(() => setIsShaking(false), 500);
      }
      
      return newRotation % 360;
    });
  }, 50); // 50ms = 20 FPS, полный оборот за 18 секунд
  
  return () => clearInterval(interval);
}, []);
```

### Применение вращения к SVG:
```tsx
<g transform={`translate(300, 380) rotate(${rotation})`}>
  {/* Буквы Б, Г, К */}
</g>
```

### Применение тряски экрана:
```tsx
<div className={`min-h-screen bg-cosmic text-white flex items-center justify-center p-6 ${isShaking ? 'animate-screen-shake' : ''}`}>
  {/* Содержимое страницы */}
</div>
```

## 🛡️ Безопасность

### Отключение эффектов:
- **Стоп-слово "бесконечность"** — отключает все эффекты, включая вращение
- **Режим ясности** — спокойная версия без анимаций
- **`prefers-reduced-motion`** — автоматическое отключение анимаций

### Производительность:
- Анимация использует `setInterval` с 50ms интервалом
- CSS-анимация тряски оптимизирована (transform, не layout)
- Минимальное влияние на производительность
