### 1. ✅ Добавлены альтернативные вопросы для манипуляции "Переписывание вопроса"

**Проблема:**
В TestPage массив allQuestions не содержал поля alternatives, поэтому ветка с переписыванием вопроса никогда не выполнялась.

**Решение:**
- Добавлены alternatives к первым 7 вопросам вручную
- Создана функция `addAlternatives()` для автоматического добавления alternatives ко всем остальным вопросам
- Функция применяется при выборе вопросов в `startTest()`

**Код:**
```typescript
// Функция для добавления alternatives к вопросам
function addAlternatives(question: Question): Question {
  if (question.alternatives && question.alternatives.length > 0) {
    return question;
  }
  
  // Создаём альтернативные вопросы на основе оригинального
  const alternatives = [
    {
      question: `Альтернатива 1: ${question.question}`,
      options: [...question.options].sort(() => Math.random() - 0.5),
      correct: Math.floor(Math.random() * question.options.length)
    },
    {
      question: `Альтернатива 2: ${question.question}`,
      options: [...question.options].sort(() => Math.random() - 0.5),
      correct: Math.floor(Math.random() * question.options.length)
    }
  ];
  
  return {
    ...question,
    alternatives
  };
}

// Применение при выборе вопросов
const shuffledQuestions = selected.map(q => shuffleOptions(addAlternatives(q)));
```

**Эффект:**
- Теперь манипуляция "Переписывание вопроса" работает корректно
- После ответа на вопрос с вероятностью 70% вопрос меняется на альтернативный
- Ответ сбрасывается, создавая эффект газлайтинга

### 2. ✅ Исправлена утечка таймеров в GaslightEffects

**Проблема:**
setTimeout внутри setInterval не сохранялись в ref, поэтому при размонтировании компонента могли остаться "висячие" таймеры.

**Решение:**
- Создана функция `safeSetTimeout()` для безопасного создания setTimeout
- Все setTimeout заменены на safeSetTimeout
- Таймеры автоматически удаляются из ref после выполнения

**Код:**
```typescript
// Функция для безопасного создания setTimeout с сохранением в ref
const safeSetTimeout = (callback: () => void, delay: number) => {
  const timer = setTimeout(() => {
    callback();
    // Удаляем таймер из ref после выполнения
    timersRef.current = timersRef.current.filter(t => t !== timer);
  }, delay);
  timersRef.current.push(timer);
  return timer;
};
```

**Эффект:**
- Нет утечек памяти
- Все таймеры корректно очищаются при размонтировании
- Стабильная работа компонента
