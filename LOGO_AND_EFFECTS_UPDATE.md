### 1. Доработка логотипа

#### 1.1. Возвращена дрожь при перевороте букв

**Что сделано:**
- Добавлена анимация тряски экрана при достижении 180° вращения
- Тряска активируется каждые 18 секунд (когда буквы переворачиваются)
- Длительность тряски: 500 мс
- Используется CSS-класс `animate-screen-shake`

**Реализация:**
```typescript
useEffect(() => {
  const interval = setInterval(() => {
    setRotation(prev => {
      const newRotation = prev + 1;
      // Тряска при достижении 180 градусов (переворот букв)
      if (newRotation % 360 === 180) {
        setIsShaking(true);
        setTimeout(() => setIsShaking(false), 500);
      }
      return newRotation % 360;
    });
  }, 50);
  return () => clearInterval(interval);
}, []);
```

**Файл:** `src/components/BGCLogo3D.tsx` (строки 5-24)

### 2. Таймер "До конца акции осталось" с постоянным продлением

**Что сделано:**
- Создан компонент `UrgencyTimer`
- Таймер обратного отсчёта (5-7 минут)
- При достижении 0 таймер автоматически продлевается
- Показывается уведомление "АКЦИЯ ПРОДЛЕНА!"
- Счётчик продлений

**Реализация:**
```typescript
// Обратный отсчёт
useEffect(() => {
  const interval = setInterval(() => {
    setTimeLeft(prev => {
      if (prev <= 1) {
        // Продление акции
        setShowExtension(true);
        setExtensionCount(c => c + 1);
        setTimeout(() => setShowExtension(false), 2000);
        return 300 + Math.floor(Math.random() * 120); // 5-7 минут
      }
      return prev - 1;
    });
  }, 1000);
  return () => clearInterval(interval);
}, []);
```

**Визуальные элементы:**
- Оранжевый таймер в правом верхнем углу
- Формат: ММ:СС
- Счётчик продлений
- Модальное окно при продлении с текстом "АКЦИЯ ПРОДЛЕНА!"

**Файл:** `src/components/UrgencyTimer.tsx`

**Газлайтинг-эффект:**
- Пользователь видит таймер и чувствует срочность
- Когда таймер доходит до 0, акция "продлевается"
- Это создаёт бесконечный цикл срочности
- Пользователь не может дождаться конца акции

### 3. Система бонусов с постоянным обновлением лицензионных условий

**Что сделано:**
- Создан компонент `BonusSystem`
- Накопление бонусных баллов каждые 5 секунд
- Обновление лицензионных условий каждые 15 секунд
- 8 разных сообщений об обновлении условий
- Счётчик обновлений

**Реализация:**
```typescript
// Накопление бонусов
useEffect(() => {
  const interval = setInterval(() => {
    setBonusPoints(prev => prev + Math.floor(Math.random() * 10) + 1);
  }, 5000); // Каждые 5 секунд
  return () => clearInterval(interval);
}, []);

// Обновление лицензионных условий
useEffect(() => {
  const messages = [
    'Лицензионное соглашение обновлено. Продолжая использование, вы соглашаетесь с новыми условиями.',
    'Условия программы лояльности изменены. Проверьте обновлённые правила.',
    // ... ещё 6 сообщений
  ];
  const interval = setInterval(() => {
    const msg = messages[Math.floor(Math.random() * messages.length)];
    setUpdateMessage(msg);
    setShowUpdate(true);
    setUpdateCount(c => c + 1);
    setTimeout(() => setShowUpdate(false), 4000);
  }, 15000); // Каждые 15 секунд
  return () => clearInterval(interval);
}, []);
```

**Визуальные элементы:**
- Лаймовый счётчик бонусов в правом верхнем углу
- Индикатор "+N каждые 5 сек"
- Уведомления об обновлении условий в правом нижнем углу
- Кнопки "Принять" и "Подробнее"

**Файл:** `src/components/BonusSystem.tsx`

**Газлайтинг-эффект:**
- Пользователь видит, как бонусы накапливаются
- Постоянные уведомления об изменении условий
- Невозможно отследить все изменения
- Создаётся ощущение потери контроля

## Психологический эффект

### Логотип с тряской:
- **Цель:** Создать ощущение нестабильности
- **Эффект:** Пользователь видит, как буквы переворачиваются (БГК → КГБ)
- **Вывод:** "Даже логотип меняется. Что ещё меняется?"

### Таймер с продлением:
- **Цель:** Создать бесконечную срочность
- **Эффект:** Пользователь не может дождаться конца акции
- **Вывод:** "Срочность никогда не заканчивается"

### Система бонусов:
- **Цель:** Создать иллюзию прогресса
- **Эффект:** Пользователь видит накопление бонусов
- **Вывод:** "Я зарабатываю бонусы, но условия постоянно меняются"

### Обновление условий:
- **Цель:** Создать ощущение потери контроля
- **Эффект:** Постоянные изменения, которые невозможно отследить
- **Вывод:** "Я не могу уследить за всеми изменениями"
