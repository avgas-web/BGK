```typescript

</button>
```

### 3. ✅ Экран службы поддержки (чат)

**Что было добавлено:**

Создан компонент `SupportChat.tsx` с полной функциональностью чата поддержки:

#### Функции:
- **Автоматическое приветствие:** "Здравствуйте! Чем могу помочь?"
- **Отправка сообщений:** Пользователь может вводить текст и отправлять

- **Автоматическое закрытие после оценки:** Через 2 секунды после оценки

1. "Мы понимаем, насколько это неудобно и приносим свои извинения. Мы обязательно примем меры."
2. "Благодарим за обращение. Ваш запрос передан в соответствующий отдел. Ожидайте ответа в течение 24-48 рабочих дней."
3. "Мы ценим вашу обратную связь. К сожалению, в данный момент мы не можем предоставить дополнительную информацию по вашему вопросу."
4. "Спасибо за ваше терпение. Наша команда работает над решением этой проблемы. Приносим извинения за временные неудобства."
5. "Мы понимаем вашу обеспокоенность. Ваш случай находится на рассмотрении у наших специалистов. Мы свяжемся с вами в ближайшее время."
6. "Благодарим за понимание. Мы постоянно работаем над улучшением качества наших услуг. Ваше мнение очень важно для нас."

#### Ограничение:
- **Максимум 3 сообщения** за весь тест
- Счётчик `mockeryCount` отслеживает количество показов
- Сбрасывается при перезапуске теста

**Код:**
```typescript
const [mockeryCount, setMockeryCount] = useState(0); // Счетчик насмешек (максимум 3)

useEffect(() => {
  if (!gaslightingEnabled || clarityMode) return;

  const interval = setInterval(() => {
    if (mockeryCount < 3 && Math.random() > 0.60) {
      const msg = mockeryMessages[Math.floor(Math.random() * mockeryMessages.length)];
      setMockeryMessage(msg);
      setShowMockery(true);
      setMockeryCount(prev => prev + 1);
      setTimeout(() => setShowMockery(false), 3500);
    }
  }, 12000);

  return () => clearInterval(interval);
}, [gaslightingEnabled, clarityMode, mockeryCount]);
```

## 🎭 Психологические эффекты

### 1. Обязательное согласие с политикой
- **Эффект:** Создаёт ощущение бюрократии и формальности
- **Цель:** Усилить чувство контроля системы над пользователем
- **Результат:** Пользователь чувствует, что должен согласиться со всем

### 2. Чат поддержки с отписками
- **Эффект:** Имитация реальной поддержки, которая ничего не решает
- **Цель:** Показать бесполезность обращения за помощью
- **Результат:** Пользователь чувствует беспомощность и разочарование

### 3. Корпоративный булшит
- **Эффект:** Формальные фразы, скрывающие унижение
- **Цель:** Показать, как корпоративный язык может быть манипулятивным
- **Результат:** Пользователь чувствует давление и неуверенность

### 4. Ограничение насмешек (3 раза)
- **Эффект:** Каждая насмешка становится более значимой
- **Цель:** Не перегружать пользователя, но создать запоминающиеся моменты
- **Результат:** Более сильное воздействие каждого сообщения
