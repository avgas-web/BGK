### 1. 3D-буквы БГК с объёмом на стартовой странице

**Изменения:**
- Буквы БГК теперь отображаются в **3D-проекции** с эффектом объёма
- Реализовано с помощью CSS 3D-трансформаций (`perspective`, `transformStyle: preserve-3d`, `translateZ`)
- Каждая буква состоит из **21 слоя** для создания эффекта глубины:
  - Задняя грань (тёмно-красная, `translateZ(-20px)`)
  - 20 промежуточных слоёв с градиентом цвета и прозрачности
  - Передняя грань (ярко-красная, `translateZ(0px)`)
- Буквы вращаются вокруг оси Y с сохранением 3D-эффекта
- При достижении 180° буквы переворачиваются и читаются как КГБ
- Экран дёргается на 0.5 секунды при переходе БГК → КГБ

**Технические детали:**
```typescript
<div style={{
  perspective: '1000px',
  perspectiveOrigin: 'center center',
}}>
  <div style={{
    transformStyle: 'preserve-3d',
    transform: `rotateY(${rotation}deg)`,
  }}>
    {/* 21 слой для каждой буквы */}
  </div>
</div>
```

**Визуальный эффект:**
- Буквы выглядят объёмными и трёхмерными
- При вращении видна глубина и тени
- Создаётся эффект "парящих" букв в пространстве

### 3. Первый вопрос всегда про цвет заголовка

**Изменения в логике выбора вопросов:**

**Было:**
```typescript
const shuffled = [...allQuestionsFinal].sort(() => Math.random() - 0.5);
const selected = shuffled.slice(0, 15);
```

**Стало:**
```typescript
// Первый вопрос всегда про цвет заголовка (id=1)
const firstQuestion = allQuestionsFinal.find(q => q.id === 1);

// Выбираем 14 случайных вопросов из остальных
const otherQuestions = allQuestionsFinal.filter(q => q.id !== 1);
const shuffled = [...otherQuestions].sort(() => Math.random() - 0.5);
const selectedOthers = shuffled.slice(0, 14);

// Объединяем: первый вопрос + 14 случайных
const selected = firstQuestion ? [firstQuestion, ...selectedOthers] : selectedOthers;
```

**Эффект:**
- Первый вопрос всегда: "Какого цвета был заголовок на предыдущем экране?"
- Остальные 14 вопросов выбираются случайно из 59 оставшихся
- Создаётся эффект "якоря" — пользователь начинает с простого вопроса
- Затем вопросы становятся сложнее и начинают меняться

### 4. Названия призов в рулетке

**Изменения:**

**Было:**
```typescript
const segments = [
  { label: 'Скидка 90%', color: '#C8FF00' },
  { label: 'Скидка 50%', color: '#7B61FF' },
  { label: 'Скидка 25%', color: '#FF6B35' },
  { label: 'Скидка 10%', color: '#A7A9B8' },
  { label: 'Скидка 5%', color: '#F4F6F8' },
  { label: 'Без скидки', color: '#14141F' },

```

**Стало:**
```typescript
const segments = [
  { label: 'Скидка 90%', fullName: 'Скидка 90% на Калибровку', color: '#C8FF00' },
  { label: 'Скидка 50%', fullName: 'Скидка 50% на курс "Маяк"', color: '#7B61FF' },
  { label: 'Скидка 25%', fullName: 'Скидка 25% на "Год на орбите"', color: '#FF6B35' },
  { label: 'Скидка 10%', fullName: 'Скидка 10% на сертификацию', color: '#A7A9B8' },
  { label: 'Скидка 5%', fullName: 'Скидка 5% на корпоративный интенсив', color: '#F4F6F8' },
  { label: 'Без скидки', fullName: 'Без скидки (но вы всё равно молодец)', color: '#14141F' },
];
```

**Эффект:**
- На колесе отображаются короткие названия (label)
- При выигрыше показывается полное название приза (fullName)
- Более описательные и конкретные названия
- Последний приз с юмористической подписью: "Без скидки (но вы всё равно молодец)"

## 🎯 Психологический эффект

### 3D-буквы:
- **Цель:** Усилить гипнотический эффект и создать ощущение глубины
- **Эффект:** Буквы выглядят объёмными и "парящими" в пространстве
- **Вывод:** "Даже буквы могут быть не такими, как кажутся"

### Вопросы 9-11 классов:
- **Цель:** Увеличить сложность теста и создать ощущение неуверенности
- **Эффект:** Пользователь сталкивается с вопросами, которые мог забыть
- **Вывод:** "Я думал, что знаю всё, но оказывается..."

### Первый вопрос про цвет:
- **Цель:** Создать "якорь" и эффект ложной уверенности
- **Эффект:** Пользователь начинает с простого вопроса, затем сложность растёт
- **Вывод:** "Сначала всё было просто, а потом..."

### Названия призов:
- **Цель:** Сделать рулетку более конкретной и описательной
- **Эффект:** Пользователь видит, на что именно он может "выиграть"
- **Вывод:** "Я выиграл скидку на Калибровку, но цена не изменилась"
