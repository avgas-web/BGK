### 3. Эффект БГК → КГБ с тряской и разбитым стеклом

**Что было добавлено:**

Каждые 30 секунд (при достижении 180° вращения):
1. Буквы меняются с "БГК" на "КГБ"
2. Цвет букв меняется с лаймового на красный
3. Экран начинает трястись (animate-screen-shake)
4. Появляется эффект разбитого стекла (красные трещины)
5. Через 3 секунды всё возвращается в нормальное состояние

**Реализация:**
```typescript
// Каждые 30 секунд показываем КГБ на 3 секунды
if (newRotation % 360 === 180) {
  setShowKGB(true);
  setIsShaking(true);
  setTimeout(() => {
    setShowKGB(false);
    setIsShaking(false);
  }, 3000);
}
```

**Визуальные эффекты:**
- SVG с красными трещинами (#FF3B3B)
- 8 основных трещин из центра
- 4 дополнительных мелких трещины
- Анимация тряски экрана
- Плавный переход цветов

### 5. Динамическая смена вопроса с сообщением

**Что было добавлено:**

При ответе на вопрос с вероятностью 70%:
1. Через 3 секунды вопрос меняется на альтернативный
2. Появляется сообщение "* вопрос изменился" (фиолетовый, мигающий)
3. Ответ сбрасывается
4. Появляется сообщение "* ваш ответ был сброшен" (оранжевый)

**Реализация:**
```typescript
// Газлайтинг: изменение вопроса
if (gaslightingEnabled && !clarityMode && Math.random() > 0.3) {
  setTimeout(() => {
    const alt = currentQ.alternatives![Math.floor(Math.random() * currentQ.alternatives!.length)];
    setSelectedQuestions(prev => prev.map((q, i) => 
      i === currentQuestion ? { ...q, question: alt.question, options: alt.options, correct: alt.correct } : q
    ));
    setQuestionRewritten(true);
    setShowQuestionChangeMessage(true);
    setTimeout(() => setShowQuestionChangeMessage(false), 3000);
    if (answers[currentQuestion] !== null) {
      setAnswers(prev => prev.map((a, i) => i === currentQuestion ? null : a));
      setAnswerChanged(true);
    }
  }, 3000);
}
```

**Визуальные эффекты:**
- Фиолетовое мигающее сообщение "* вопрос изменился"
- Оранжевое сообщение "* ваш ответ был сброшен"
- Метка "[ПЕРЕПИСАН]" рядом с номером вопроса

**Файлы:**

### 6. Сброс бонусов при достижении 5000

**Что было добавлено:**

При достижении 5000 бонусов:
1. Появляется модальное окно с сообщением "БОНУСЫ СГОРЕЛИ!"
2. Показывается иконка огня 🔥
3. Текст: "Вы достигли 5000 бонусов, но они сгорели из-за изменения условий программы."
4. Подтекст: "Начисление начинается заново..."
5. Через 3 секунды бонусы сбрасываются до 0
6. Модальное окно закрывается

**Реализация:**
```typescript
// Проверка достижения 5000 бонусов и сброс
useEffect(() => {
  if (bonusPoints >= 5000) {
    setShowBurnMessage(true);
    setTimeout(() => {
      setBonusPoints(0);
      setShowBurnMessage(false);
    }, 3000);
  }
}, [bonusPoints]);
```

**Визуальные эффекты:**
- Модальное окно по центру экрана
- Красная рамка (border-red/50)
- Иконка огня 🔥
- Красный заголовок
- Анимация появления/исчезновения
