## 🎭 Вращающийся логотип БГК

### Визуальные эффекты:
- **Красные буквы** БГК медленно вращаются на стартовой странице
- **Скорость вращения:** 1 градус каждые 50ms (20 градусов/сек)
- **Полный оборот:** 18 секунд (360 градусов)
- **Эффект КГБ:** при 180° буквы переворачиваются и читаются как КГБ
- **Тряска экрана:** 0.5 секунды при переходе БГК → КГБ

### Психологический эффект:
- **Гипнотическое вращение** создаёт ощущение транса
- **Переход БГК → КГБ** демонстрирует, как контекст меняет восприятие
- **Тряска экрана** создаёт ощущение нестабильности реальности
- **Вывод:** "То, что вы видите, зависит от того, как вы на это смотрите"

### Технические детали:
```typescript
// Анимация вращения
useEffect(() => {
  const interval = setInterval(() => {
    setRotation(prev => {
      const newRotation = prev + 1;
      
      // При 180° (КГБ) запускаем тряску
      if (newRotation % 360 === 180) {
        setIsShaking(true);
        setTimeout(() => setIsShaking(false), 500);
      }
      
      return newRotation % 360;
    });
  }, 50);
  
  return () => clearInterval(interval);
}, []);
```

## 🛡️ Безопасность и доступность

### Стоп-слово "Бесконечность"
- Кнопка-иконка ⏹ в правом нижнем углу
- Раскрывающаяся панель с полем ввода
- Подсказка: "слово из 13 букв"
- Отключает все эффекты

### Режим ясности
- Кнопка "◎ Ясность" в навигации
- Переключает между "Режим спектакля" и "Режим ясности"
- В режиме ясности все эффекты отключены

### Доступность (Accessibility)
- `aria-live="polite"` для динамических сообщений
- `role="alert"` для важных уведомлений
- `aria-label` для кнопок без текста
- `aria-modal="true"` для модалок
- Focus trap для модальных окон

### Адаптивность
- Мобильные устройства: эффекты появляются реже
- Слабые устройства (deviceMemory < 4): максимум 3 эффекта
- `prefers-reduced-motion`: все эффекты отключаются

```bash

npm install

npm run dev

# Открыть http://localhost:3000
```

```bash
npm run build
```

Собраные файлы будут в папке `dist/`

1. Создайте репозиторий на GitHub
2. Запушьте код в ветку `main` или `master`
3. Перейдите в **Settings → Pages**
4. В разделе **Source** выберите **GitHub Actions**
5. Workflow запустится автоматически

Сайт будет доступен по адресу: `https://<username>.github.io/<repository-name>/`
