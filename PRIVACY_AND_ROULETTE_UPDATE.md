## 🎯 Внесённые изменения

### 1. ✅ Обработка отклонения политики конфиденциальности

**Что было добавлено:**

При нажатии кнопки "Отклонить" в политике конфиденциальности:
- Появляется сообщение: "Продолжая использовать сайт, вы автоматически соглашаетесь с Политикой конфиденциальности"
- Сообщение отображается 3 секунды
- После этого политика закрывается автоматически

**Реализация:**

```typescript
const [showAutoAccept, setShowAutoAccept] = useState(false);

const handleReject = () => {
  setShowAutoAccept(true);
  setTimeout(() => {
    setShowAutoAccept(false);
    onClose();
  }, 3000);
};
```

**UI:**
```tsx
{/* Auto-accept message */}
{showAutoAccept && (
  <motion.div
    initial={{ opacity: 0, y: 20 }}
    animate={{ opacity: 1, y: 0 }}
    exit={{ opacity: 0, y: 20 }}
    className="fixed bottom-8 left-1/2 -translate-x-1/2 z-[10000] max-w-md"
  >
    <div className="bg-orange/90 backdrop-blur border-2 border-orange rounded-lg p-4 shadow-[0_0_30px_rgba(255,107,53,0.5)]">
      <p className="text-white text-sm font-mono text-center">
        Продолжая использовать сайт, вы автоматически соглашаетесь с Политикой конфиденциальности
      </p>
    </div>
  </motion.div>
)}
```

**Эффект:**
- Газлайтинг-эффект: пользователь не может отказаться от политики
- Создаёт ощущение безвыходности
- Демонстрирует манипуляцию через "автоматическое согласие"

## 🎮 Как работает рулетка

### Гарантированный выигрыш 90%:

```typescript
const spinRoulette = () => {
  if (isSpinning) return;

  setIsSpinning(true);
  setResult(null);
  setShowComment(false);

  // Всегда выигрывает скидку 90% (индекс 0)
  const winningIndex = 0;
  const segmentAngle = 360 / segments.length;
  // Добавляем случайное смещение и накапливаем вращение
  const randomOffset = Math.random() * 30 - 15; // ±15 градусов
  const spins = 5 + Math.floor(Math.random() * 3); // 5-7 полных оборотов
  const targetRotation = rotation + spins * 360 + (360 - winningIndex * segmentAngle - segmentAngle / 2) + randomOffset;

  setRotation(targetRotation);

  setTimeout(() => {
    setIsSpinning(false);
    setResult(segments[winningIndex].fullName);
    setTimeout(() => setShowComment(true), 1000);
  }, 4000);
};
```

**Ключевые моменты:**
- `winningIndex = 0` - всегда выигрывает первый сегмент (90%)
- Случайное смещение создаёт иллюзию случайности
- 5-7 полных оборотов для реалистичности
- Результат всегда "Скидка 90% на Калибровку"
