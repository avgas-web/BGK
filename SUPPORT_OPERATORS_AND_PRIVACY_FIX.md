### 3. ✅ Политика конфиденциальности открывается поверх стартовой страницы

**Что было изменено:**

**Было:**
- При клике на ссылку политики конфиденциальности стартовая страница закрывалась
- Открывалась страница политики конфиденциальности
- Пользователь "проскакивал" стартовую страницу без дачи согласия

**Стало:**
- При клике на ссылку политики конфиденциальности она открывается как **модальное окно поверх стартовой страницы**
- Стартовая страница остаётся открытой
- Пользователь может прочитать политику конфиденциальности
- После закрытия политики пользователь возвращается к стартовой странице
- Пользователь может дать согласие на стартовой странице

**Реализация:**

```typescript
// В WarningPage.tsx
const [showPrivacyPolicy, setShowPrivacyPolicy] = useState(false);

<button
  type="button"
  onClick={(e) => {
    e.preventDefault();
    e.stopPropagation();
    setShowPrivacyPolicy(true);
  }}
  className="text-lime font-semibold underline hover:text-lime/80 transition-colors"
>
  Политикой конфиденциальности
</button>

{/* Политика конфиденциальности как модальное окно поверх WarningPage */}
{showPrivacyPolicy && (
  <PrivacyPolicy onClose={() => setShowPrivacyPolicy(false)} />
)}
```

**Файлы:**
- `src/components/WarningPage.tsx` - добавлено состояние и модальное окно
- `src/App.tsx` - убран обработчик `onShowPrivacy`

### 4. ✅ Исправлена ошибка с переходом без согласия

**Проблема:**
При попытке прочитать политику конфиденциальности пользователь переходил на сайт без дачи согласия.

**Решение:**
- Политика конфиденциальности теперь открывается как модальное окно поверх стартовой страницы
- Стартовая страница не закрывается
- Пользователь должен дать согласие на стартовой странице после прочтения политики

**Результат:**
- ✅ Пользователь может ознакомиться с политикой до дачи согласия
- ✅ Пользователь не может "проскочить" стартовую страницу
- ✅ Оба согласия (условия сайта + политика конфиденциальности) обязательны
