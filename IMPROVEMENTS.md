# Улучшения сайта — Финальная версия

## ✅ Реализованные улучшения

### 1. Универсальный компонент GaslightOverlay
**Файл:** `src/components/GaslightOverlay.tsx`

Вместо 20+ копий оверлеев создан один компонент с пропсами:
- `variant`: 'info' | 'warning' | 'danger' | 'success' | 'system' | 'scary'
- `position`: 'top-left' | 'top-right' | 'bottom-left' | 'bottom-right' | 'center' | 'top-center' | 'bottom-center'
- `title`, `message`, `icon`
- `jitter`, `pulse` — эффекты анимации
- `onDismiss` — кнопка закрытия
- `ariaLive` — поддержка скринридеров

**Преимущества:**
- Единый стиль для всех уведомлений
- Легко добавлять новые типы
- Встроенная доступность (aria-live, role="alert")

### 2. Конфиг-файл со всеми фразами
**Файл:** `src/config/gaslightConfig.ts`

Все тексты газлайтинга собраны в одном месте:
- 20+ типов паттернов с фразами
- Настройки частот и вероятностей
- FAQ с пренебрежительными ответами
- Утилиты для определения возможностей устройства

**Преимущества:**
- Легко редактировать тексты
- Централизованное управление
- Возможность A/B тестирования фраз

### 3. Доступность (Accessibility)
**Добавлено:**
- `aria-live="polite"` для динамических сообщений
- `role="alert"` для важных уведомлений
- `aria-label` для кнопок без текста
- `aria-modal="true"` для модалок
- Focus trap для модальных окон

**Компонент FocusTrap:**
```typescript
<FocusTrap active={showModal}>
  <ModalContent />
</FocusTrap>
```

Автоматически удерживает фокус внутри модалки при навигации с клавиатуры.

### 4. Ограничение эффектов для слабых устройств
**Файл:** `src/config/gaslightConfig.ts`

Функция `getDeviceCapabilities()` определяет:
- `isMobile` — мобильное устройство
- `deviceMemory` — объём памяти (из navigator.deviceMemory)
- `prefersReducedMotion` — настройка ОС
- `isLowEnd` — устройство с памятью < 4 ГБ
- `slowdownFactor` — коэффициент замедления (1x, 1.5x, 2x)
- `maxConcurrentEffects` — максимум одновременных эффектов (3, 5, 10)

**Применение:**
- На мобильных устройствах эффекты появляются реже
- На слабых устройствах (deviceMemory < 4) максимум 3 эффекта одновременно
- При `prefers-reduced-motion` все эффекты отключаются

### 5. Кнопка "Стоп" как иконка
**Изменения в App.tsx:**

**Было:** Поле ввода стоп-слова всегда видимо
```tsx
<input placeholder="Введите для остановки..." />
```

**Стало:** Кнопка-иконка в правом нижнем углу
```tsx
<button aria-label="Открыть панель стоп-слова">
  <span>⏹</span>
</button>
```

При клике раскрывается панель с полем ввода:
- Красная кнопка с иконкой остановки
- Анимация раскрытия панели
- Подсказка: "слово из 13 букв"
- autoFocus на поле ввода

**Преимущества:**
- Не занимает место на экране
- Более интуитивно (красная кнопка = стоп)
- Доступность через aria-label

## 🎯 Психологический эффект улучшений

### Кнопка "Стоп" как иконка:
- **До:** Поле ввода всегда видимо → пользователь видит "выход"
- **После:** Красная кнопка-иконка → более интуитивно, но всё равно доступно
- **Эффект:** Стоп-слово остаётся доступным, но не навязчивается

### Газлайтинг в контактах:
- **Механизм:** Пользователь нажимает "Показать телефон" → видит email с "вам показалось"
- **Эффект:** Демонстрация того, как интерфейс обманывает ожидания
- **Вывод:** "Даже контакты могут газлайтить"

### Ограничение эффектов:
- **Механизм:** На слабых устройствах эффекты появляются реже
- **Эффект:** Сайт остаётся доступным для всех пользователей
- **Вывод:** Газлайтинг не должен вредить

## 🛡️ Безопасность и доступность

### Поддержка скринридеров:
- Все динамические сообщения имеют `aria-live="polite"`
- Важные уведомления имеют `role="alert"`
- Кнопки без текста имеют `aria-label`
- Модалки имеют `aria-modal="true"`

### Focus management:
- Focus trap удерживает фокус внутри модалок
- autoFocus на полях ввода при раскрытии
- Клавиатурная навигация работает корректно

### Адаптивность:
- Мобильные устройства: эффекты появляются реже
- Слабые устройства (deviceMemory < 4): максимум 3 эффекта
- `prefers-reduced-motion`: все эффекты отключаются
