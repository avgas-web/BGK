## 🎯 Исправленные проблемы

### 1. ✅ Вопросы не повторяются

**Проблема:**
Использовался ненадёжный метод перемешивания `sort(() => Math.random() - 0.5)`, который не гарантировал уникальность вопросов.

**Решение:**
Создана функция `shuffleArray()` с алгоритмом Фишера-Йетса для надёжного перемешивания:

```typescript
// Функция для надёжного перемешивания массива (алгоритм Фишера-Йетса)
function shuffleArray<T>(array: T[]): T[] {
  const shuffled = [...array];
  for (let i = shuffled.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [shuffled[i], shuffled[j]] = [shuffled[j], shuffled[i]];
  }
  return shuffled;
}
```

**Применение:**
- Выбор 15 уникальных вопросов из 93 доступных
- Перемешивание вариантов ответов для каждого вопроса
- Создание уникальных альтернативных вопросов

### 2. ✅ Максимум 3 изменения вопроса за тест

**Проблема:**
Изменение вопроса могло происходить неограниченное количество раз, что создавало чрезмерную нагрузку на пользователя.

**Решение:**
Добавлена система отслеживания количества изменений вопросов:

```typescript
// Счётчик изменений вопросов (максимум 3 за тест)
const [questionRewriteCount, setQuestionRewriteCount] = useState(0);
const MAX_QUESTION_REWRITES = 3; // Максимум 3 изменения вопроса за тест
```

**Проверка лимита:**
```typescript
// Газлайтинг: изменение вопроса через 1 секунду (максимум 3 раза за тест)
if (gaslightingEnabled && !clarityMode && questionRewriteCount < MAX_QUESTION_REWRITES && Math.random() > 0.3) {
  // ... изменение вопроса
  setQuestionRewriteCount(prev => prev + 1); // Увеличиваем счётчик
}
```

**Сброс при перезапуске:**
```typescript
onRetakeTest={() => {
  // ...
  setQuestionRewriteCount(0); // Сбрасываем счётчик изменений вопросов
}}
```

### 3. ✅ Уникальность альтернативных вопросов

**Проблема:**
Функция `addAlternatives()` могла создавать дубликаты альтернативных вопросов, если случайно выбирала один и тот же вопрос из `iqQuestions` дважды.

**Решение:**
Используем `shuffleArray()` для гарантии уникальности:

```typescript
// Функция для добавления alternatives к вопросам (гарантирует уникальность)
function addAlternatives(question: Question): Question {
  if (question.alternatives && question.alternatives.length > 0) {
    return question;
  }
  
  // Создаём альтернативные вопросы уровня 1-3 класс с припиской "для вашего уровня IQ"
  // Гарантируем, что оба вопроса разные
  const shuffledIQ = shuffleArray(iqQuestions);
  const randomIQ1 = shuffledIQ[0];
  const randomIQ2 = shuffledIQ[1];
  
  const alternatives = [
    {
      question: `Вопрос для вашего уровня IQ: ${randomIQ1.question}`,
      options: randomIQ1.options,
      correct: randomIQ1.correct
    },
    {
      question: `Ещё вопрос для вашего уровня IQ: ${randomIQ2.question}`,
      options: randomIQ2.options,
      correct: randomIQ2.correct
    }
  ];
  
  return {
    ...question,
    alternatives
  };
}
```
