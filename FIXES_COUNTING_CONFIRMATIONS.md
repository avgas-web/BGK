## 🎯 Внесённые изменения

### 1. Исправлен счетчик правильных ответов

**Проблема:**
Счетчик неправильных ответов показывал неправильное количество правильных ответов.

**Причина:**
При перемешивании вариантов ответов в `shuffleOptions` мы обновляем `correct` индекс в `selectedQuestions`. Но в `correctAnswersCount` мы сравнивали `answer` (индекс выбранного варианта в перемешанном списке) с `originalQuestion.correct` (индекс правильного ответа в ОРИГИНАЛЬНОМ списке).

**Решение:**
Теперь мы сравниваем `answer` с `selectedQuestions[index].correct`, что правильно учитывает перемешивание вариантов.

**Код:**
```typescript
// Было (неправильно):
const correctAnswersCount = answers.reduce<number>((count, answer, index) => {
  if (answer === null) return count;
  const originalQuestion = allQuestions.find(q => q.id === selectedQuestions[index]?.id);
  if (originalQuestion && answer === originalQuestion.correct) {
    return count + 1;
  }
  return count;
}, 0);

// Стало (правильно):
const correctAnswersCount = answers.reduce<number>((count, answer, index) => {
  if (answer === null) return count;
  const selectedQ = selectedQuestions[index];
  if (selectedQ && answer === selectedQ.correct) {
    return count + 1;
  }
  return count;
}, 0);
```

**Эффект:**
- Теперь счетчик правильно показывает количество правильных ответов
- Учитывается перемешивание вариантов ответов
- Статистика в TestDebrief теперь корректна

### 2. Ограничение подтверждений ответов (максимум 3)

**Проблема:**
Окно подтверждения ответа могло появляться неограниченное количество раз.

**Решение:**
Добавлен счетчик `confirmCount`, который ограничивает количество подтверждений до 3 за весь тест.

**Код:**
```typescript
// Добавлен счетчик
const [confirmCount, setConfirmCount] = useState(0);

// Проверка перед показом окна
if (gaslightingEnabled && !clarityMode && confirmCount < 3 && Math.random() < 0.19) {
  setPendingAnswer(optionIndex);
  setShowConfirmAnswer(true);
  setConfirmCount(prev => prev + 1);
  return;
}

// Сброс счетчика при перезапуске теста
onRetakeTest={() => {
  // ...
  setConfirmCount(0);
}}
```

**Эффект:**
- Окно подтверждения появляется максимум 3 раза за тест
- После 3 подтверждений окно больше не появляется
- Счетчик сбрасывается при перезапуске теста
- Более предсказуемое поведение системы

### 3. Отслеживание манипуляции подтверждения ответа

**Проблема:**
Подтверждение ответа не отслеживалось в списке манипуляций.

**Решение:**
Добавлен вызов `trackManipulation` в функции `confirmAnswer`.

**Код:**
```typescript
const confirmAnswer = () => {
  if (pendingAnswer !== null) {
    const newAnswers = [...answers];
    newAnswers[currentQuestion] = pendingAnswer;
    setAnswers(newAnswers);
    setPendingAnswer(null);
    setShowConfirmAnswer(false);
    
    // Отслеживаем манипуляцию подтверждения ответа
    trackManipulation(
      'answer_confirmation',
      'Подтверждение ответа',
      'Появилось окно с требованием подтвердить свой ответ, заставив усомниться в выборе',
      'https://ru.wikipedia.org/wiki/Газлайтинг'
    );
  }
};
```

**Эффект:**
- Подтверждение ответа теперь отображается в списке манипуляций
- Пользователь видит, сколько раз его заставляли подтверждать ответ
- Полная статистика всех манипуляций в TestDebrief

## 🎭 Психологические эффекты

### 1. Правильный счетчик
- **Эффект:** Пользователь видит реальную статистику
- **Цель:** Показать реальный результат, а не манипулировать статистикой
- **Результат:** Более честная обратная связь

### 2. Ограничение подтверждений
- **Эффект:** Ограниченное количество подтверждений
- **Цель:** Не перегружать пользователя подтверждениями
- **Результат:** Более предсказуемое поведение системы

### 3. Отслеживание подтверждений
- **Эффект:** Пользователь видит все манипуляции
- **Цель:** Показать полную картину манипуляций
- **Результат:** Полная прозрачность всех воздействий
