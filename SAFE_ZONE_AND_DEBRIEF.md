### 1. Сейф-зона: Заметная кнопка "Режим ясности"

**Создан компонент:** `src/components/SafeZoneButton.tsx`

**Преимущества:**
- Заметная, но не кричащая
- Не ломает атмосферу сайта

- Понятная иконка и подсказки

### 2. Адаптация под Mobile

**Изменения в `src/App.tsx`:**

#### Курсор-трейл
- Отключён на мобильных устройствах
- Проверка через `navigator.userAgent`
- Экономит ресурсы и не мешает тапам

#### Отзывы
- Добавлена поддержка `onTouchStart` и `onTouchEnd`
- При касании отзывы меняются на 2 секунды
- Работает как long press на мобильных

**Изменения в `src/components/GaslightEffects.tsx`:**

#### Exit-intent модалка
- Отключена на мобильных устройствах
- Проверка через `navigator.userAgent`
- На мобильных не работает mouseleave, поэтому модалка не показывается

**Изменения в `src/index.css`:**

#### Мобильные стили
```css
@media (hover: none) {
  /* Отключаем hover-эффекты на мобильных */
  .hover\:text-lime:hover { color: inherit; }
  .hover\:bg-lime\/20:hover { background-color: inherit; }
  /* ... */
  
  /* Добавляем active-состояния для кнопок */
  button:active,
  a:active {
    transform: scale(0.98);
    opacity: 0.8;
  }
  
  /* Long press эффект */
  .long-press::after {
    content: '';
    position: absolute;
    inset: 0;
    background: rgba(200, 255, 0, 0.2);
    border-radius: inherit;
    opacity: 0;
    transition: opacity 0.3s;
  }
  .long-press:active::after {
    opacity: 1;
  }
}
```

**Результат:**
- Hover-эффекты не срабатывают на мобильных
- Кнопки имеют визуальную обратную связь при нажатии
- Long press эффект для интерактивных элементов
- Курсор-трейл не мешает тапам
- Exit-intent модалка не показывается на мобильных

**Что показывает:**

Каждая манипуляция содержит:
- **Название:** "Переписывание вопроса", "Изменение ответа", "Манипуляция памятью" и т.д.
- **Описание:** Что именно происходило
- **Счётчик:** Сколько раз это произошло
- **Ссылка:** На статью в Википедии о том, как противостоять

#### Отслеживаемые манипуляции:
1. **Переписывание вопроса** — вопрос изменился после вашего ответа

3. **Манипуляция памятью** — вам внушали ложные воспоминания
4. **Отрицание реальности** — вам говорили, что вы ошибаетесь
5. **Краш теста** — тест "сломался", заставив начать заново
