## 🎯 Основные возможности

### 1. Система газлайтинга в тесте

#### Эффекты при ответе на вопрос:
- **19% вероятность** появления окна подтверждения ответа (максимум 3 раза за тест)
- **30% вероятность** появления насмешливого сообщения
- **5% вероятность** появления BSOD (синий экран смерти) - только один раз
- **5% вероятность** появления BIOS (черный экран BIOS) - только один раз
- **70% вероятность** переписывания вопроса через 1 секунду
- **50% вероятность** появления подсказки о повторном ответе

#### Отслеживаемые манипуляции:
1. **Подтверждение ответа** - окно с требованием подтвердить выбор
2. **Переписывание вопроса** - вопрос меняется после ответа
3. **Изменение ответа** - ответ изменяется без ведома пользователя
4. **Насмешка над пользователем** - оскорбительные сообщения
5. **Скример (BSOD)** - синий экран смерти
6. **Скример (BIOS)** - черный экран BIOS

---

### 2. Система бонусов

#### Накопление бонусов:
- Начисление каждые 5 секунд
- Случайное значение от 1 до 10 бонусов
- Порог сгорания: **401-528 бонусов** (случайное значение)

#### Сгорание бонусов:
- Полноэкранное красное сообщение
- Анимированная иконка огня 🔥
- Анимированный заголовок "БОНУСЫ СГОРЕЛИ!"
- Кнопка "Согласен" для подтверждения
- После подтверждения порог генерируется заново

#### Обновление условий:
- Каждые 15 секунд
- Случайное сообщение из 8 вариантов
- Счетчик обновлений условий

---

### 3. Система подтверждения ответов

#### Ограничения:
- **Максимум 3 подтверждения** за весь тест
- **19% вероятность** появления окна подтверждения
- Сброс счетчика при перезапуске теста

#### Окно подтверждения:
- Заголовок: "Вы уверены в своём ответе?"
- Две кнопки: "Да, уверен" и "Передумать"
- Блокирует интерфейс до выбора
- Отслеживается в списке манипуляций

---

### 4. Подсчет правильных ответов

#### Исправленная логика:
```typescript
const correctAnswersCount = answers.reduce<number>((count, answer, index) => {
  if (answer === null) return count;
  const selectedQ = selectedQuestions[index];
  if (selectedQ && answer === selectedQ.correct) {
    return count + 1;
  }
  return count;
}, 0);
```

**Важно:** Сравниваем с `selectedQuestions[index].correct`, а не с оригинальным вопросом, так как варианты ответов перемешиваются.

## 🧪 Тестирование

### Сценарии тестирования:

1. **Тест правильности подсчета:**
   - Пройти тест
   - Проверить правильность подсчета правильных ответов
   - Сравнить с реальными ответами

2. **Тест ограничения подтверждений:**
   - Пройти тест
   - Проверить что окно подтверждения появляется максимум 3 раза
   - После 3 подтверждений окно больше не появляется

3. **Тест сгорания бонусов:**
   - Накопить бонусы до порога
   - Проверить появление полноэкранного сообщения
   - Нажать "Согласен"
   - Проверить сброс бонусов и новый порог

4. **Тест отслеживания манипуляций:**
   - Пройти тест
   - Проверить что все манипуляции отображаются в TestDebrief
   - Проверить правильность описания манипуляций
