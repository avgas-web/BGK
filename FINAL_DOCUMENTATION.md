## 🎯 Основные возможности

### 1. Система газлайтинга в тесте

#### Эффекты при ответе на вопрос:
- **19% вероятность** появления окна подтверждения ответа (максимум 3 раза за тест)
- **30% вероятность** появления насмешливого сообщения
- **5% вероятность** появления BSOD (синий экран смерти) - только один раз
- **5% вероятность** появления BIOS (черный экран BIOS) - только один раз
- **70% вероятность** переписывания вопроса через 1 секунду
- **50% вероятность** появления подсказки о повторном ответе

#### Эффекты при возврате на предыдущий вопрос:
- **100% вероятность** появления обвинения в нечестности
- Сообщение: "Попытка возврата. Это нечестная сдача теста."
- Отслеживается в списке манипуляций

#### Отслеживаемые манипуляции (7 типов):
1. **Подтверждение ответа** - окно с требованием подтвердить выбор
2. **Переписывание вопроса** - вопрос меняется после ответа
3. **Изменение ответа** - ответ изменяется без ведома пользователя
4. **Насмешка над пользователем** - оскорбительные сообщения
5. **Скример (BSOD)** - синий экран смерти
6. **Скример (BIOS)** - черный экран BIOS
7. **Обвинение в нечестности** - обвинение при возврате на предыдущий вопрос

### 2. Система бонусов

#### Накопление бонусов:
- Начисление каждые 5 секунд
- Случайное значение от 1 до 10 бонусов
- Порог сгорания: **401-528 бонусов** (случайное значение)

#### Сгорание бонусов:
- Полноэкранное красное сообщение
- Анимированная иконка огня 🔥
- Анимированный заголовок "БОНУСЫ СГОРЕЛИ!"
- Кнопка "Согласен" для подтверждения
- После подтверждения порог генерируется заново

#### Обновление условий:
- Каждые 15 секунд
- Случайное сообщение из 8 вариантов
- Счетчик обновлений условий

---

### 3. Система подтверждения ответов

#### Ограничения:
- **Максимум 3 подтверждения** за весь тест
- **19% вероятность** появления окна подтверждения
- Сброс счетчика при перезапуске теста

#### Окно подтверждения:
- Заголовок: "Вы уверены в своём ответе?"
- Две кнопки: "Да, уверен" и "Передумать"
- Блокирует интерфейс до выбора
- Отслеживается в списке манипуляций

### 4. Справочник манипуляций

#### Доступность:
- Доступен **только в режиме ясности**
- Кнопка: "📖 Справочник манипуляций"
- Расположение: левый нижний угол

#### Содержимое справочника:

**Введение:**
- Что такое газлайтинг
- Цель газлайтинга
- Описание справочника

**Список манипуляций (7 типов):**

1. **Подтверждение ответа** (`answer_confirmation`)
   - Описание: Появляется окно с требованием подтвердить свой ответ
   - Воздействие: Заставляет усомниться в своём выборе, создаёт дополнительное давление
   - Суть: Манипуляция через сомнение

2. **Переписывание вопроса** (`question_rewrite`)
   - Описание: Вопрос изменился после вашего ответа
   - Воздействие: Заставляет усомниться в памяти, сбивает с толку
   - Суть: Манипуляция через изменение реальности

3. **Изменение ответа** (`answer_change`)
   - Описание: Ваш ответ был изменён без вашего ведома
   - Воздействие: Потеря контроля над своими действиями, чувство беспомощности
   - Суть: Манипуляция через потерю контроля

4. **Насмешка над пользователем** (`mockery`)
   - Описание: Появилось оскорбительное сообщение
   - Воздействие: Унижает интеллектуальные способности, снижает самооценку
   - Суть: Манипуляция через унижение

5. **Скример (синий экран смерти)** (`bsod_screen`)
   - Описание: Внезапное появление пугающего изображения
   - Воздействие: Вызывает страх и отвлечение внимания
   - Суть: Манипуляция через страх

6. **Скример (чёрный экран BIOS)** (`bios_screen`)
   - Описание: Внезапное появление пугающего изображения
   - Воздействие: Вызывает страх и отвлечение внимания
   - Суть: Манипуляция через страх

7. **Обвинение в нечестности** (`dishonesty_accusation`)
   - Описание: При возврате на предыдущий вопрос появилось обвинение в нечестной сдаче теста
   - Воздействие: Заставляет усомниться в своих действиях, создаёт чувство вины
   - Суть: Манипуляция через обвинение

**Раздел "Как противостоять манипуляциям?":**
1. Доверяйте своим ощущениям
2. Ведите записи
3. Обсуждайте с другими
4. Устанавливайте границы
5. Обращайтесь за помощью

### 5. Подсчет правильных ответов

#### Исправленная логика:
```typescript
const correctAnswersCount = answers.reduce<number>((count, answer, index) => {
  if (answer === null) return count;
  const selectedQ = selectedQuestions[index];
  if (selectedQ && answer === selectedQ.correct) {
    return count + 1;
  }
  return count;
}, 0);
```

**Важно:** Сравниваем с `selectedQuestions[index].correct`, а не с оригинальным вопросом, так как варианты ответов перемешиваются.

## 🧪 Тестирование

### Сценарии тестирования:

1. **Тест правильности подсчета:**
   - Пройти тест
   - Проверить правильность подсчета правильных ответов
   - Сравнить с реальными ответами

2. **Тест ограничения подтверждений:**
   - Пройти тест
   - Проверить что окно подтверждения появляется максимум 3 раза
   - После 3 подтверждений окно больше не появляется

3. **Тест сгорания бонусов:**
   - Накопить бонусы до порога
   - Проверить появление полноэкранного сообщения
   - Нажать "Согласен"
   - Проверить сброс бонусов и новый порог

4. **Тест отслеживания манипуляций:**
   - Пройти тест
   - Проверить что все манипуляции отображаются в TestDebrief
   - Проверить правильность описания манипуляций

5. **Тест обвинения в нечестности:**
   - Пройти тест
   - Вернуться на предыдущий вопрос
   - Проверить появление сообщения "Попытка возврата. Это нечестная сдача теста."
   - Проверить что манипуляция `dishonesty_accusation` отображается в TestDebrief

6. **Тест справочника манипуляций:**
   - Включить режим ясности
   - Проверить появление кнопки "📖 Справочник манипуляций"
   - Нажать на кнопку
   - Проверить открытие справочника
   - Проверить наличие всех 7 типов манипуляций
   - Проверить наличие раздела "Как противостоять манипуляциям?"
   - Проверить ссылки на Wikipedia

7. **Тест доступности справочника:**
   - Выключить режим ясности
   - Проверить что кнопка справочника не отображается
   - Включить режим ясности
   - Проверить что кнопка справочника отображается
