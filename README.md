# Базз Газлайтер Клуб — Финальная версия

## 🎭 О проекте

Иммерсивная платформа критического мышления и эмоциональной устойчивости. Сайт использует художественные приёмы газлайтинга в образовательных целях.

**Важно:** Это демонстрация. Вы в безопасности. Стоп-слово — "Бесконечность".

---

## ✨ Что реализовано

### 🎨 Основные функции

1. **Страница-предупреждение** с SVG-логотипом (шлем Базза + буквы БГК)
2. **20+ типов газлайтинг-эффектов** (отрицание, переписывание истории, ложные подтверждения и др.)
3. **Тест на подверженность газлайтингу** (15 вопросов с динамическими изменениями)
4. **Тревожные окна-ловушки** с фейковыми подтверждениями
5. **Страшные эффекты** (BSOD, трещины, экран блокировки)
6. **Обвинение в неоплаченном интернете**
7. **Динамический FAQ** с пренебрежительными ответами

### 🛡️ Безопасность и доступность

- **Стоп-слово "бесконечность"** — кнопка-иконка в правом нижнем углу
- **Режим ясности** — спокойная версия без газлайтинга
- **Поддержка prefers-reduced-motion** — автоматическое отключение анимаций
- **aria-live** для всех динамических сообщений
- **Focus trap** для модальных окон
- **Адаптивность** — ограничение эффектов для мобильных и слабых устройств

### 🎯 Улучшения последней версии

#### 1. Универсальный компонент GaslightOverlay
Вместо 20+ копий оверлеев создан один компонент с пропсами:
- 6 вариантов стилей (info, warning, danger, success, system, scary)
- 7 позиций на экране
- Встроенная доступность (aria-live, role="alert")

#### 2. Конфиг-файл со всеми фразами
Все тексты газлайтинга собраны в `src/config/gaslightConfig.ts`:
- 20+ типов паттернов с фразами
- Настройки частот и вероятностей
- FAQ с пренебрежительными ответами
- Утилиты для определения возможностей устройства

#### 3. Доступность (Accessibility)
- `aria-live="polite"` для динамических сообщений
- `role="alert"` для важных уведомлений
- `aria-label` для кнопок без текста
- `aria-modal="true"` для модалок
- Focus trap для модальных окон

#### 4. Ограничение эффектов для слабых устройств
Функция `getDeviceCapabilities()` определяет:
- Мобильное устройство или десктоп
- Объём памяти (navigator.deviceMemory)
- Настройку prefers-reduced-motion
- Коэффициент замедления (1x, 1.5x, 2x)
- Максимум одновременных эффектов (3, 5, 10)

#### 5. Кнопка "Стоп" как иконка
**Было:** Поле ввода стоп-слова всегда видимо
**Стало:** Красная кнопка-иконка ⏹ в правом нижнем углу

При клике раскрывается панель с полем ввода и подсказкой "слово из 13 букв".

#### 6. Обновлённая команда
- **Максим Орбитов** (Технический директор) → **Авгас** (Концепт-директор)
- Описание: "Архитектор смыслов и визуальных метафор. Превращает идеи в иммерсивные миры."

#### 7. Обновлённые контакты с газлайтингом
- **Город:** Санкт-Петербург
- **Адрес:** "Адрес уточняется"

**Газлайтинг-эффект:** Пользователь нажимает "Показать телефон", но видит email с подписью "вам показалось". Демонстрация того, как интерфейс обманывает ожидания.

## 🚀 Быстрый старт

### Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Открыть http://localhost:3000
```

### Сборка для продакшена

```bash
npm run build
```

Собраные файлы будут в папке `dist/`

### Деплой на GitHub Pages

1. Создайте репозиторий на GitHub
2. Запушьте код в ветку `main` или `master`
3. Перейдите в **Settings → Pages**
4. В разделе **Source** выберите **GitHub Actions**
5. Workflow запустится автоматически

Сайт будет доступен по адресу: `https://<username>.github.io/<repository-name>/`

## 🛡️ Безопасность

### Стоп-слово
Введите "бесконечность" в поле стоп-слова или нажмите кнопку ⏹ в правом нижнем углу.

Все эффекты немедленно отключаются, появляется сообщение:
> "Вы в безопасности. Это была демонстрация. Бесконечность — не предел. Особенно бесконечность осознанности."

### Режим ясности
Кнопка "◎ Ясность" в навигации переключает между режимами:
- **Режим спектакля** — все эффекты активны
- **Режим ясности** — спокойная версия без газлайтинга

### Предупреждение
При первом заходе показывается страница-предупреждение с информацией о возможных эффектах и чекбоксом согласия.
